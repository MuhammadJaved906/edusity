Project Name: Edusity
Type: University Landing Page
Built with: React.js 19, Vite 8, react-scroll

Sections:

Navbar (sticky, changes style on scroll)
Hero (banner with CTA button)
Programs (Graduation, Masters, Post-Graduation)
About (university info with image)
Campus Gallery (4 photos)
Testimonials (sliding carousel with 4 student reviews)
Contact (form + phone, email, address)
Footer

Key Features:

Smooth scroll navigation via react-scroll
Sticky navbar on scroll
Interactive testimonial slider (built with useRef)
Reusable Title component for section headings
Component-level CSS styling

Project Structure: 9 components, each in its own folder with its own CSS file
Scripts: npm run dev · npm run build · npm run preview · npm run lint
Dependencies: react, react-dom, react-scroll
Dev Dependencies: Vite, ESLint, @vitejs/plugin-react
